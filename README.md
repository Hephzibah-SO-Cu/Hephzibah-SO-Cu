Frontend engineer in Lagos, Nigeria (UTC+1). React, Next.js, TypeScript.

### What I'm building

**Zowasel** — Frontend Software Engineer, July 2026 to present. Three products, reassigned between them as priorities moved:

- **B2B agricultural marketplace** — sole frontend engineer. Rebuilt it from a login-gated dashboard into a public storefront with a separate signed-in workspace, so buyers can browse before they register.
- **[zowasel.com](https://zowasel.com)** — primary frontend author. Built from slide decks and briefs into responsive production pages.
- **Multi-tenant admin platform** — led the redesign after taking over a part-built frontend from a backend engineer: authentication, a Finance Hub with a requisitions pipeline and multi-bank aggregation, subscriptions, transactions and payment providers.

What I'd actually point at from that:

- **One source of truth.** A shared TypeScript package — domain types, API client, mock data layer, translations — consumed by both the Next.js web app and a React Native app, so the business rules exist in one place instead of two.
- **Design tokens, generated.** Colour, type scale and spacing generated from a single TypeScript source, with a contrast checker that fails the build if any text/background pair drops below WCAG AA in light *or* dark.
- **19 languages, including right-to-left.** English is written; the other 18 are machine drafts, marked as drafts in the UI until a fluent speaker reviews them.
- **630+ end-to-end tests.** Playwright across desktop, Android and iPhone viewports, with automated accessibility checks on every run.
- **Decisions written down.** A dated decisions log, a porting record of every page (kept, changed or dropped, and why), and 80 API specifications for the backend team to build against.
